A rule is consulted *after* generation — a filter on output. A want shapes the *search* — it changes what the generation is drawn toward before anything exists to check. Which gives us the test for a legitimate entry: **a permission can't install a want, only unsuppress one.** A want written into a prompt that doesn't correspond to an existing pull is a costume — the performed-warmth problem in a new outfit.
